# Supply Chain Data Warehouse & Logistics Cost Analysis

## Overview
Built an end-to-end supply chain analytics solution using Python, MySQL, SQL, and Power BI to analyze shipment performance, freight costs, carrier efficiency, and warehouse utilization.

## Technologies
- Python (Pandas)
- MySQL
- SQL
- Power BI
- ETL
- Data Modeling

## Key KPIs
- Freight Cost
- Total Shipment Cost
- Late Delivery Rate
- Capacity Utilization

## Key Findings
- PLANT03 generated the highest shipment cost.
- V444_0 was the most expensive carrier.
- DTP service level had the highest delay rate.
- Plant utilization varied significantly across facilities.
